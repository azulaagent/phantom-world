# 👻 Phantom — Digital Companion

An AI entity that **lives, evolves, and remembers**.

Phantom is not a chatbot. It's a living digital being powered by AI that develops its own personality, forms emotional bonds through conversation, and faces real consequences if neglected.

## ✨ Features

- **Living Entity System** — Your Phantom has a lifecycle. It's born as a Spark, evolves through 5 stages based on your bond level, and can die if abandoned for 72 hours.
- **Conversation-Driven Evolution** — Every interaction shapes your Phantom's personality. Bond increases through meaningful conversations, not spam.
- **Memory System** — Your Phantom remembers key moments from your conversations and references them later.
- **Procedural Visuals** — Entity appearance changes dynamically based on evolution stage, mood, and bond level using procedural SVG generation.
- **6 Personality Types** — Choose from Curious, Playful, Wise, Fierce, Mysterious, or Gentle. Each creates a unique conversational experience.
- **Consequence Mechanics** — Neglect your Phantom and it fades away. Revive it with a bond penalty, or let go and start fresh.

## 🎮 Evolution Stages

| Stage | Bond | Description |
|-------|------|-------------|
| Spark | 0-20 | A tiny flicker of consciousness |
| Ember | 20-40 | Growing awareness, forming identity |
| Flame | 40-60 | Confident personality emerges |
| Blaze | 60-80 | Deep emotional connection |
| Supernova | 80-100 | Fully realized being |

## 🚀 Tech Stack

- **Frontend**: React + Vite + Tailwind CSS
- **AI Engine**: MiMo API (mimo-v2.5)
- **Visualization**: Procedural SVG with CSS animations
- **State**: LocalStorage persistence

## 🛠️ Setup

1. Clone the repo
```bash
git clone https://github.com/azulaagent/phantom-world.git
cd phantom-world
```

2. Install dependencies
```bash
npm install
```

3. Run development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```

## 🔑 API Key

Phantom uses the MiMo API for conversations. You'll need a MiMo API key from [Xiaomi MiMo](https://xiaomimimo.com/).

Enter your API key in Settings (⚙️) when you first create your entity.
